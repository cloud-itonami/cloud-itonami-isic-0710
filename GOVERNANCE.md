# Governance

This project is part of the cloud-itonami fleet of industry actors and follows
the same governance model as all siblings in that fleet.

## Decision Making

- **Architectural decisions** are recorded as ADRs in `docs/adr/`.
- **Code changes** follow the standard PR review process.
- **Breaking changes** require ADR + discussion before implementation.

## Maintenance

This repository is maintained as part of the broader kotoba-lang/industry
ecosystem. For questions or issues:

1. Check existing ADRs in `docs/adr/`
2. Review the README and GOVERNANCE.md
3. Open an issue or discussion with details
